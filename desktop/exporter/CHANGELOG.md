# Changelog

## 0.1.7

- 保留滤镜输出时间基，避免左右眼捕获时间略有差异时默认编码时间基将相邻帧舍入为重复 DTS；保持 passthrough，不以强制丢帧或忽略编码错误绕过失败。
- 视频处理仍失败时自动保存原始左右眼视频、音频分段和 manifest 到独立 `-raw` 目录，并显示“未拼接、未转码”的弹窗、保存路径及失败原因。
- 原始兜底不记录合并视频成功标记；批量任务继续后续条目并汇总警告。取消、源读取失败、目标冲突不触发兜底，复制失败不发布未完成目录。
- 新增单段/多段时间戳碰撞复现、输出 DTS 和帧数核对、兜底字节一致性、取消、不覆盖及批量标记回归。
- 本次继续仅打包 Windows amd64；macOS/Ubuntu 发布包不变。

## 0.1.6

- Windows 修复版：使用 QueryDosDevice 和只读 DeviceIoControl 枚举 USB/SD/MMC 物理磁盘与分区，读卡检测不再依赖 PowerShell、Get-Disk 或 Get-Partition。
- 打开读取句柄后再次核实外置总线及分区偏移/长度，避免设备编号重用时误读内置盘；继续校验 OpenAria 卷协议。
- 记录 Windows 版本、管理员状态、原生接口失败阶段及系统错误；新增“导出诊断信息”菜单，不自动上传、不包含录像内容。
- 增加原生磁盘布局 ABI、MBR/GPT、边界溢出、总线白名单及 PowerShell 不可用回归。
- 本次只构建、发布 Windows amd64 安装包；Mac/Ubuntu 继续使用 0.1.5。构建目标由 release-platforms.json 显式指定。

## 0.1.5

- 桌面客户端集成至 SDK 仓库的 desktop/exporter，独立版本与 exporter-v* 发布标签。
- 新增三平台原生回归、完整安装包构建、包内媒体烟雾测试、SHA256 和 GitHub Actions 构建产物。
- macOS 完整包附带 FFmpeg/ffprobe 及重定位动态库，不再依赖用户安装 Homebrew。
- Windows/Linux 媒体依赖固定到可审计的上游版本及 SHA256；构建失败时不上传不完整安装包。
- 本机历史初始化和写入使用 immediate 事务，避免多个客户端同时初始化数据库时的锁升级争用；CI 重复验证 Windows 并发写入。

## 0.1.4

- Ubuntu 完整安装包支持附带已校验的 Linux amd64 FFmpeg/ffprobe 和许可说明，避免 Ubuntu 22.04 系统 FFmpeg 4.4 无法导出的问题。
- 编码前检查所需 FFmpeg 参数，旧版本明确提示使用完整包，不再无效重试编码器。
- ext4 测试优先查找系统 mke2fs，使 Ubuntu 原生嵌套镜像和超过 4GiB 的稀疏文件测试实际运行。

## 0.1.3

- 新增本机持久“已导出”标记，按录制卷、录像及媒体版本关联；拔插、重启、盘符变化后恢复，各电脑独立记录。
- 新增“删除本机成品”和“清除标记”，分别确认；删除成品保留标记，清除标记保留文件。
- 本机成品删除核对导出记录及文件状态，拒绝链接、额外文件和变化的成品，与导出共用锁。
- GUI 和 CLI 均逐条保存成功导出记录；保存失败明确提示已完成的视频仍然存在。
- 卡内原始录像删除尚未实现：当前 ext4 及特权服务仍只读，不将未验证的裸盘写入作为可用功能交付。

## 0.1.2

- 修复 Windows 编码完成后发布目录时出现 Access is denied：通过目录外锁保持互斥和不覆盖语义。
- Windows 安装包支持同时交付 FFmpeg、ffprobe 及其许可和说明文件；本轮交付包含媒体工具。
- 完成 Windows 11 实际读卡、SQLite/WAL 和媒体导出回归。

## 0.1.1

- 修复 Windows SQLite 临时库 URI 把盘符误认为服务器地址、无法扫描录像的问题。
- Windows 读卡检测和媒体工具不再创建 PowerShell/控制台窗口。

## 0.1.0

- 原生双栏录像扫描和导出界面。
- 三平台安装包，手动签名更新与任务退出保护。
